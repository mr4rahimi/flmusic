# کارهای باقی‌مانده

## در فاز ۱ عمداً انجام نشد

### احراز هویت و بخش کاربری

API همه‌ی این‌ها را دارد ولی UI وب ندارد:
ورود/ثبت‌نام، آپلود آهنگ، لایک، کامنت، دنبال‌کردن، پلی‌لیست‌های شخصی،
نوتیفیکیشن، فید «دنبال‌شده‌ها».

نکته‌ی مهم برای پیاده‌سازی: توکن JWT **نباید** در `localStorage` بماند.
روش درست در Next، کوکی `httpOnly` است که در Route Handler ست می‌شود.
راهنما: `node_modules/next/dist/docs/01-app/02-guides/authentication.md`

### صفحه‌بندی فهرست‌ها

الان `/new` و `/trending` فقط ۴۸ آیتم اول را نشان می‌دهند.
برای SEO بهتر است `/new/2`، `/new/3` … با `rel=prev/next` منطقی داشته باشند
تا آهنگ‌های قدیمی‌تر هم مسیر خزش پیدا کنند.

### کامنت‌ها روی صفحه‌ی آهنگ

`GET /tracks/:trackId/comments` عمومی است. نمایش کامنت‌ها هم محتوای
اضافه برای گوگل تولید می‌کند هم `UserComments` را به schema اضافه می‌کند.

## بهبودهای شناخته‌شده

### خطای ۵۰۰ در endpoint جستجوی API

`GET /api/v1/search?q=...` روی سرور خطای ۵۰۰ برمی‌گرداند (احتمالاً
Meilisearch ایندکس ندارد یا سرویسش در دسترس نیست). صفحه‌ی `/search`
به‌خاطر `apiGetSafe` خطا نمی‌دهد و «نتیجه‌ای پیدا نشد» نشان می‌دهد،
ولی جستجو عملاً کار نمی‌کند — هم در وب هم در اپ موبایل.

بررسی روی سرور:

```bash
pm2 logs music_meilisearch --lines 50 --nostream
curl 'http://127.0.0.1:3000/api/v1/search?q=test&type=tracks'
```

### نوار پیشرفت با waveform

جدول `tracks` ستون `waveformData` (آرایه‌ی عددی) دارد که هنوز استفاده
نشده. نمایش موج صوتی به‌جای نوار ساده، تجربه‌ی کاربری بهتری می‌دهد.

### باطل‌سازی فوری کش

برچسب‌های کش (`track:<id>`, `feed`, …) ست شده‌اند ولی هنوز چیزی
`revalidateTag()` صدا نمی‌زند. یک Route Handler محافظت‌شده که API
پس از آپلود آهنگ صدایش بزند، محتوای تازه را بدون انتظار برای انقضا
منتشر می‌کند.

### `generateSitemaps` برای مقیاس بزرگ‌تر

توضیح در [02-seo.md](02-seo.md) بخش «رشد sitemap».

### بهینه‌سازی تصویر روی کاورهای دور

`next/image` تصویر را سمت سرور واکشی و بهینه می‌کند. هنگام تست لوکال،
واکشی کاور از `185.164.73.224` گاهی تایم‌اوت می‌شد
(`upstream image response timed out`). روی خود سرور مسیر کوتاه‌تر است،
ولی ارزش دارد بعد از دیپلوی یک بار چک شود:

```bash
curl -s -o /dev/null -w "%{http_code}\n" \
  "https://flmusic.ir/_next/image?url=https%3A%2F%2Fflmusic.ir%2Fuploads%2Fcovers%2F<file>.jpg&w=640&q=75"
```

اگر ۵۰۰ داد، ساده‌ترین راه این است که کاورها بدون بهینه‌سازی سرو شوند
(nginx از قبل با `Cache-Control: immutable` سروشان می‌کند).

### بخش «داغ‌ترین‌ها» وقتی خالی است

`getTrendingFeed` در API فقط آهنگ‌های **۷ روز اخیر** را برمی‌گرداند.
اگر مدتی آپلود جدیدی نباشد، این بخش در صفحه‌ی اصلی خالی می‌ماند —
هم برای کاربر بد است هم صفحه‌ی اصلی را کم‌محتوا نشان می‌دهد.
دو راه: بازه را در API بازتر کنید، یا در وب وقتی خالی بود بخش را
اصلاً رندر نکنید.

## مواردی که تصمیم شما را لازم دارد

۱. **نام ستون‌های `genre`/`tags`** — سمت وب حل شده: `genre` به‌عنوان
   خواننده و `tags` به‌عنوان سبک خوانده می‌شود
   ([05-api-integration.md](05-api-integration.md)). ولی نام ستون در
   دیتابیس هنوز گمراه‌کننده است. اگر روزی migration زدید،
   `genre → singerName` و `tags → styles` منطقی‌ترند؛ سمت وب فقط دو
   helper در `src/lib/types.ts` باید عوض شود.

   کار مفیدتر و فوری‌تر: **پرکردن `tags` برای آهنگ‌های قدیمی**. بیشتر
   ردیف‌ها `tags: null` دارند، پس صفحات `/style/*` کم‌محتوا می‌مانند.

۲. **نشت ایمیل در `/profiles/:username`** — اصلاحش کنیم؟ باید اول
   بررسی شود اپ موبایل به آن وابسته نیست.
   ([05-api-integration.md](05-api-integration.md))

۳. **اجبار HTTPS در پنل پارس‌پک** — الان `http://flmusic.ir` هم پاسخ
   می‌دهد و ریسک ایندکس‌شدن نسخه‌ی http وجود دارد.

۵. **گواهی SSL روی خود سرور منقضی شده** — `/etc/ssl/flmusic/fullchain.pem`
   در ۲۳ ژوئیه ۲۰۲۶ منقضی شده. سایت اصلی آسیب نمی‌بیند (CDN گواهی خودش
   را دارد و کانفیگ ما فقط پورت ۸۰ است) ولی بلوک ۴۴۳ سایت
   `api.flmusic.ir` از همان استفاده می‌کند.

۴. **لینک دانلود اپ فندوق** — `NEXT_PUBLIC_APP_DOWNLOAD_URL` هنوز خالی
   است، پس دکمه‌ی دانلود در بخش معرفی اپ رندر نمی‌شود. آدرس مایکت/بازار/
   APK مستقیم را بگذارید و build دوباره بزنید (متغیر `NEXT_PUBLIC_` است).

۵. **endpointهای سبک در API** — `GET /feed/tags` و `GET /feed/tag/:tag`.
   وب از قبل صداشان می‌زند و در نبودشان fallback می‌کند، ولی fallback
   فقط ۳۰۰ آهنگ اخیر را می‌بیند
   ([05-api-integration.md](05-api-integration.md)).
